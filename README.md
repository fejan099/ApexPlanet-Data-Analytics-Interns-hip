# ApexPlanet Data Analytics Internship

## Task 1: Data Immersion & Wrangling

This project focuses on understanding, cleaning, validating, and preparing a sales dataset for further data analysis.

## Objective

- Understand the structure of the raw sales dataset
- Identify missing values and duplicate records
- Check data types and data quality
- Detect potential outliers using the IQR method
- Clean and transform the dataset
- Create a data dictionary
- Prepare an analysis-ready dataset

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- Microsoft Excel
- GitHub

## Data Cleaning Performed

- Handled missing Age values using the median
- Handled missing City values using the mode
- Converted Order_Date into datetime format
- Checked duplicate rows and duplicate Order IDs
- Detected numerical outliers using the IQR method
- Validated Total_Sales
- Removed temporary calculation columns
- Performed final data-quality checks

## Project Files

- `data_cleaning_wrangling.ipynb` – Data cleaning and wrangling notebook
- `cleaned_sales_dataset.csv` – Final cleaned dataset
- `data_dictionary.xlsx` – Description of dataset columns
- `data_quality_summary.xlsx` – Data quality checks and summary

## Final Dataset

The final dataset contains 1,000 records and 12 columns with no missing values or exact duplicate rows.
